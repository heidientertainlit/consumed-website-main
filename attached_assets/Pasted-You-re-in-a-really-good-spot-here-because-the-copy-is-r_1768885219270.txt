## The 5 specific tweaks I’d make (no copy changes required)

### 1. Give the headline more *vertical authority*

Right now it’s doing too much work in one block.

**Fix:**

* Increase line-height slightly
* Add a bit more space *below* it

This lets it feel like a statement, not a paragraph.

---

### 2. Visually soften “See how you stack up.”

The words are right, but the visual weight is competing with the headline.

**Fix:**

* Reduce opacity slightly (or lighter gray)
* Slightly smaller font size
* Keep it tight to the headline

It should feel like a *knowing aside*, not a second headline.

---

### 3. Make the “Across what you’re playing.” line feel like motion, not text

This line is conceptually great — it just needs to **feel different**.

**Fix options (pick one):**

* Smaller size + increased letter spacing
* Lower contrast than subheadline
* Slightly more space above it
* Animate only the *word swap*, not the whole line

You want it to feel like:

> “Oh yeah — this applies everywhere.”

Not:

> “Here is another sentence.”

---

### 4. Pull the CTA *down* just a bit

Right now the CTA is visually too close to the copy block.

**Fix:**

* Add more vertical spacing above the button
* Let the copy breathe
* Button should feel like a next step, not part of the paragraph

This also increases perceived confidence.

---

### 5. Reduce visual noise near the bottom

The avatars + “Join early adopters…” line is nice, but it’s competing with the hero.

**Fix:**

* Lower opacity
* Slightly smaller
* More spacing from CTA

This makes the hero feel calmer and more intentional.
